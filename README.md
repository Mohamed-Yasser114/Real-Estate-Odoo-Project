# Real Estate Management Module

## Overview
An Odoo module for managing real estate properties, owners, and property-related operations.

## Features
- Manage property details, pricing, bedrooms, areas, and facilities.
- Manage property owners and assign tags to properties.
- Implement property workflows with Draft, Pending, Sold, and Closed states.
- Calculate the difference between expected and selling prices.
- Generate property reference numbers using sequences.
- Track expected selling dates and identify overdue properties.
- Maintain property state change history, including users, reasons, and property details.
- Provide a wizard for changing property states.
- Generate QWeb HTML reports containing property and owner information.
- Configure security groups and record rules to control property access.
- Customize views and menus for properties and property history.
- Integrate Chatter and Activities for communication and tracking.

## Technologies
- Python
- Odoo ORM
- XML
- QWeb
- PostgreSQL
